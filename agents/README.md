# Functional agent team

These role cards let coding and robotics-design Codex sessions cooperate through one protocol. Initialize a role with `tools/agent init <human> <role>` and read the matching file in `agents/roles/`.

The coordinator owns task decomposition, not every implementation decision. Domain agents own recommendations in their discipline. Integration owns evidence that the assembled robot satisfies the agreed interfaces and tests. Humans retain final authority over safety, spending, fabrication, wiring, and physical operation.
